# RipenAI TFLite model analysis

Evaluated **3363** held-out test images using the exported Android TFLite model.

- Accuracy: **83.85%**
- Macro F1: **73.92%**
- Weighted F1: **84.58%**
- Fruit identity accuracy: **92.86%**
- Ripeness stage accuracy: **89.71%**
- Exact fruit + stage accuracy: **83.85%**

See `metrics.json` and `predictions.csv` for the full audit trail. PNG files are static review charts.
