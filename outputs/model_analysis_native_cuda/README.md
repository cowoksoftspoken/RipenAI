# RipenAI TFLite model analysis

Evaluated **3360** held-out test images using the exported Android TFLite model.

- Accuracy: **85.74%**
- Macro F1: **77.41%**
- Weighted F1: **85.87%**
- Fruit identity accuracy: **92.74%**
- Ripeness stage accuracy: **91.46%**
- Exact fruit + stage accuracy: **85.74%**

See `metrics.json` and `predictions.csv` for the full audit trail. PNG files are static review charts.
